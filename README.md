🇸🇬 Singapore HDB Resale Analytics Dashboard (2026)An interactive, responsive, client-side data analytics dashboard designed to visualize and analyze the resale market of government-subsidized Housing & Development Board (HDB) flats in Singapore for the year 2026.👉 Access the Live Dashboard here: https://danawiraprama.github.io/sg-prop-dashboard/💡 Why This Dashboard MattersBuying or selling a home in Singapore is one of the most critical financial decisions most citizens will make. However, HDB resale transaction data is massive, often spanning tens of thousands of rows annually.Sifting through raw .csv or .xlsx files is overwhelming. This dashboard transforms complex, raw data into high-impact, interactive visualizations within seconds, helping users spot market anomalies, price shifts, and valuation structures effortlessly.🎯 Target Audience & Value PropositionHome Buyers:Value: Avoid overpaying for flats. Instantly verify the historical median transaction prices of your target neighborhood before putting down an offer.Home Sellers:Value: Discover a realistic, market-driven valuation for your property. Setting a price aligned with local real-time trends accelerates transactions.Property Agents:Value: Utilize as a professional client-facing presentation tool. Back your local recommendations with data-driven charts rather than speculation.Market Analysts & Investors:Value: Observe micro-economic trends and shifts across diverse towns and flat sizes in the Singapore housing market.📊 Key Features & Visual AnalyticsThe dashboard is structured into several core analytical components:1. Dynamic Sidebar FiltersMulti-Select Filters: Filter down data by specific Towns (e.g., Bishan, Tampines, Queenstown) and Flat Types (e.g., 3-Room, 4-Room, Executive).Granular Control: The charts and KPIs automatically adjust in real-time, allowing you to isolate highly specific market segments.2. High-Level KPI IndicatorsTotal Transactions: Monitors market liquidity and transaction volume.Median Resale Price: The central indicator representing fair market value in the selected segment.Median Price / Sqm: Standardized unit-price per square meter to assess real value for money when comparing flat spaces.3. Price Trend by Month (Interactive Line Chart)Evaluates whether the selected market segment is growing, stable, or declining throughout 2026. Useful for timing buying or selling decisions.4. Cross-Region Price Comparison (Horizontal Bar Chart)Offers a side-by-side comparison of median resale prices among selected towns. Instantly highlights premium central estates (like Queenstown or Central Area) against suburban areas.5. Price vs. Floor Area (Interactive Scatter Plot)Explores the relationship between flat size (Sqm) and final transaction value. Allows users to spot outliers—such as unusually compact units commanding record premiums.6. Recent Transactions TableLists the 10 most recent real transactions matching your active filters. Displays detailed variables including street address, unit size, and precise pricing.🛠️ Technical Architecture & StackTo keep deployment incredibly simple, lightweight, and serverless, this dashboard is built on a modern no-build frontend stack:Markup & Structure: HTML5Styling Framework: Tailwind CSS CDNVisualization Engine: Plotly.js CDN (Highly responsive, smooth animations, and zooming/hover states)CSV Engine: PapaParse CDN (Fast, in-browser parsing of the local CSV file)Iconography: FontAwesome 6 & Google Fonts (Inter)🚀 How to Run LocallyBecause the dashboard retrieves the HDB dataset asynchronously, web browsers may block the data request locally due to CORS security policies if you simply double-click index.html.To run or test it locally with your real CSV data:Clone the Repository:git clone https://github.com/danawiraprama/sg-prop-dashboard.git
cd sg-prop-dashboard
Serve with a Local Web Server:
Using Python (standard on macOS/Linux):python -m http.server 8000
Or using Node.js npx:npx serve .
Open in Browser:
Go to http://localhost:8000 or http://localhost:3000 to interact with the full dashboard connected to your real CSV file.
(Note: If opened offline or without a server, the dashboard automatically deploys a robust sample-data generator to ensure the interface still renders properly.)📁 Repository Structure├── index.html                  # Main application structure, styling, and JavaScript logic
